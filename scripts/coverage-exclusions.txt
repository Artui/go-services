# Statements that cannot be reached, one per line, as the full import path and
# function name, followed by the reason. Keep this list short: an entry is a
# claim that the statement is unreachable, and a reviewer is entitled to check
# it.
#
# The full path matters. One exclusions file serves every module in the repo, so
# a bare "params.go:EncodeParams" would exempt a function of that name in any
# module that grew one.
#
# Go has no branch coverage, so this file is the compensating record. It is the
# honest cost of the statement-only gate, and it is meant to be read.

github.com/Artui/go-services/params.go:EncodeParams
#   The json.Marshal error branch. payload holds only values produced by the
#   JSON decoder (nil, bool, json.Number, string, []any, map[string]any) or by
#   coerce (string, int64, float64, bool, []any). Every one of those is
#   marshalable, so the error cannot occur. The check stays because discarding
#   an error to satisfy a coverage number is the worse trade.

github.com/Artui/go-services/adkx/result.go:succeed
#   The json.Decode error branch. raw came out of json.Marshal one line above,
#   so it is valid JSON by construction and decoding it into an any cannot
#   fail. The check stays because discarding an error to satisfy a coverage
#   number is the worse trade -- the same call this file already makes for
#   EncodeParams.

github.com/Artui/go-services/aguix/stream.go:Emit
#   The json.Marshal error branch. Event is a flat struct of strings and one
#   EventType, every one of which marshals, so the error cannot occur. The
#   check stays because a stream that silently dropped a frame it could not
#   encode would be worse than one that stopped.

github.com/Artui/go-services/aguix/toolbox.go:Definitions
#   Two json.Marshal error branches, input and output, on the same argument.
#   Each value is the *jsonschema.Schema the kernel reflected at registration,
#   which Register already round-tripped to build the resolved schema it
#   validates against -- an unmarshalable one could not have been registered.
#   The `entry.Output != nil` guard beside the second is unreachable for the
#   same reason: reflectSchema returns a schema for every output type, including
#   an empty struct, so Register never stores a nil. It is kept because mcpx and
#   adkx carry the identical guard, and a reader comparing the three adapters
#   should find them agreeing rather than wondering which one is wrong.

github.com/Artui/go-services/schema.go:checkDeclarationMarshals
#   The json.Unmarshal error branch. encoding/json compacts whatever MarshalJSON
#   returns and fails there, so anything json.Marshal accepts is valid JSON by
#   construction and this arm cannot be reached -- the marshal arm above catches
#   the case instead, which TestADeclaringTypeThatMarshalsNonJSONIsRefused
#   asserts explicitly so this justification fails loudly if it stops holding.
#   The check stays because reading the bytes without decoding them would be
#   trusting a promise this function exists to stop trusting.
